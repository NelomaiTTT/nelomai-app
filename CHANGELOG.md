# Изменения

## 0.3.1

- Ускорение отключения туннеля за счет фоновых процессов
- Android: ускорение переподключения за счет сохранения часовой горячей аренды при использовании резервного туннеля
- Исправления в текстах ошибок

## 0.3.0

- Android: добавлено резервное подключение для Tic/Tak и Stray с автоматическим переключением при отказе основного туннеля. Состояние резерва отображается в приложении.
- Добавлена возможность переключиться на встроенную стабильную версию 0.2.20 без переустановки приложения.
- Android: улучшены запуск VPN из плитки быстрых настроек и восстановление фоновой авторизации после обновления.
- Windows: исправлено завершение серверной аренды при повторной остановке VPN. При недоступности правил split-tunnel сохраняется доступ к локальной сети, а их последующее получение не перезапускает работающий туннель.
- Внизу настроек теперь отображается установленная версия приложения.

## 0.2.20

- Исправлена недоступная кнопка запуска VPN после обновления приложения.
- Исправлено отображение подключения и авторизации при остановке VPN для обновления.
- Android: исправлен срыв запуска VPN из плитки быстрых настроек.
- Android: устранено падение VPN-службы при временной недоступности управляющего процесса.
- Снижена нагрузка на процессор фоновой службы на macOS, Windows и Linux.
- Проверка обновлений больше не отключает VPN при медленном ответе сервера, а установка корректно ожидает завершения проверки.

## 0.2.19

- Исправлены ложные ошибки авторизации и подготовки приложения при запуске.
- Android: исправлена ошибка подготовки приложения, которая могла приводить к остановке туннеля.
- Android: исправлен запуск счётчиков трафика и фоновых задач после восстановления приложения.
- Android: устранены лишние запуски VPN-службы при выключенном подключении.
- Android: исправлено восстановление фоновой авторизации.
- Раздел «Что нового» теперь получает актуальные описания версий с панели и сохраняет их локально.

## 0.2.18

- Исправлено зависание подготовки приложения после обновления при истечении сессии. Восстановление выполняется без повторного входа.
