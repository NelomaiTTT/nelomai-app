# Изменения

## 0.2.16 — в разработке, не выпущена

- macOS: автоматическое восстановление туннеля учитывает сон и DarkWake; после полноценного пробуждения сети даётся 15 секунд перед возобновлением восстановления. Ручное управление VPN не задерживается.
- Desktop: локальная остановка VPN больше не ждёт серверной очистки аренды; очистка запускается сразу в фоне и сохраняется для повторов после перезапуска приложения.
- Android: исправлено восстановление состояния плитки после остановки VPN-сервиса.
- Подготовка совместимости с будущей встроенной стабильной версией: общий владелец авторизации, изолированные хранилища runtime и безопасное завершение туннеля перед переключением или обновлением.
- Исправлен выбор подписанного native-engine и привязка команд к версии текущего процесса; ожидающее переключение не меняет адресата команд остановки. Добавлено безопасное обновление истёкшего access после однозначного отказа сервера без повторения потерянного refresh.
- Android: общий системный VPN-dispatcher и отдельная сборка стабильного runtime для будущего встраивания. Установлен только актуальный runtime; пользовательского переключателя стабильной версии в 0.2.16 нет.
- Android hot-standby из текущего main в эту maintenance-версию не переносится.

Список будет уточнён после завершения задач сборки, ревью и аппаратной проверки. Этот раздел не подтверждает готовность релиза.
