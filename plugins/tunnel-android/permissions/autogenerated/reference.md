## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-probe`
- `allow-request-vpn-permission`
- `allow-start-smoke-tunnel`
- `allow-stop-smoke-tunnel`
- `allow-smoke-tunnel-status`
